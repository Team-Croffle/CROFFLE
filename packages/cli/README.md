# @croffledev/croffle-cli

CLI for scaffolding, building, and packaging Croffle plugins.

```bash
pnpm dlx @croffledev/croffle-cli create my-plugin
# or
pnpm dlx create-croffle-plugin my-plugin
```

```bash
pnpm dlx @croffledev/croffle-cli build
pnpm dlx @croffledev/croffle-cli pack
```

Plugin types live in `@croffledev/croffle-types`. A separate SDK library package may be added later.
